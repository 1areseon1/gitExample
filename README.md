#  Проект «Учёт аренды помещений»

> **Информационная система** для автоматизации процессов сдачи в аренду коммерческих и нежилых помещений (офисы, склады, торговые площади).

---

##  Описание предметной области

Система предназначена для автоматизации процессов сдачи в аренду **коммерческих и нежилых помещений**. Предметная область включает:

- **Учёт помещений**: номер, площадь, тип, расположение, статус.
- **Состояние помещения**: *рабочее*, *требует ремонта*, *занято*.
- **Договоры аренды**: данные об арендаторе, даты начала и окончания, стоимость, условия.
- **Занятость**: отслеживание помещений на выбранные даты.
- **История**: выдача и возврат помещений.
- **Уведомления техслужбы**: о неисправностях.
- **Оплата**: статус оплаты и закрытие договоров.

---

###  Польза для пользователей:
- **Администратор** экономит время на оформлении и снижает риск ошибок.
- **Арендатор** быстро получает информацию о свободных помещениях и сроках.
- **Организация** повышает эффективность использования недвижимости и уменьшает простои.

---

##  Пользователи системы

###  Администратор
Управляет помещениями и договорами:
- Добавляет новые помещения и договоры.
- Проверяет доступность помещения на даты.
- Проверяет состояние помещения.
- Выдаёт помещение арендатору.
- Закрывает договор.
- Уведомляет техслужбу о неисправностях.
- Просматривает отчёты и историю аренды.

###  Арендатор
Использует помещение и взаимодействует с системой:
- Проверяет доступность помещения на нужные даты.
- Просматривает информацию о помещении.
- Использует помещение после выдачи.
- Возвращает помещение.
- Проверяет состояние помещения при возврате.
- Просматривает свои договоры и сроки аренды.

> **Совпадающие действия:** проверка доступности помещения и проверка состояния помещения.

---

##  Основные функции

| Функция | Описание |
|---------|----------|
| **Добавление новой записи** | Создание договора аренды с проверкой доступности помещения |
| **Проверка доступности** | Проверка, свободно ли помещение на выбранные даты |
| **Проверка состояния** | Оценка работоспособности помещения перед выдачей и после возврата |
| **Выдача помещения** | Передача ключей и доступа арендатору |
| **Использование помещения** | Период, когда арендатор пользуется помещением |
| **Возврат помещения** | Приём помещения обратно с фиксацией состояния |
| **Закрытие договора** | Завершение аренды и освобождение помещения |
| **Уведомление техслужбы** | Сообщение о неисправностях |
| **Просмотр отчётов** | Список свободных и занятых помещений, история аренды |
| **Ведение реестра помещений** | Хранение и обновление информации о помещениях |
